
# 🌍 ISS Tracker Project

This project contains a set of tasks related to tracking and analyzing the position of the International Space Station (ISS) using Python.

## 📑 Tasks Overview

- **Task 1 to Task 7**: Implemented using Jupyter Notebooks. Each task handles specific data processing, API usage, or visualization related to the ISS.
- **Task 8**: A Streamlit-based live tracker app for real-time ISS location.

> ⚠️ **Note:**  
> **Task 8 is not implemented in a Jupyter Notebook** because Streamlit applications cannot be executed in a Jupyter environment.

---

## 🚀 Running Task 8: Streamlit ISS Tracker App

To run the **Task 8 Streamlit app**, follow these steps:

1. Open a terminal or command prompt.
2. Activate your virtual environment (if using one).
3. Run the following command:

```bash
streamlit run iss_tracker_app.py
```

This will launch the ISS Tracker web application in your browser.

---

## 🛠️ Installation

To install the required libraries, use:
